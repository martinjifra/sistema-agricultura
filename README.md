# Dashboard team — irrigation system

`team/dashboard` is the visual dashboard team's local handoff branch. Own `frontend/src/modules/dashboard/` within the shared React + Vite + TypeScript application. `/dashboard` is a public placeholder; no feature functionality is implemented.

Start with [the dashboard handoff guide](doc/team-guide.md) for scope, route contracts, verification, and open decisions.
